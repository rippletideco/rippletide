# Delete Optimization Item

Remove one candidate improvement from an agent's optimization queue.

<Warning>
  This is a destructive cleanup action. Use it only when the optimization item
  is no longer useful or was created by mistake.
</Warning>

Use this after listing optimization items and choosing a specific `itemId` to
remove.

## Endpoint

```http
DELETE /api/agents/{agentId}/optimization-items/{itemId}
```

## Authentication

Send your platform API key in the `x-api-key` header.

## Path Parameters

| Name | Type | Description |
| --- | --- | --- |
| `agentId` | `string<uuid>` | Evaluation agent ID. |
| `itemId` | `string<uuid>` | Optimization item ID. |

## Success Response

Returns `204 No Content` when the optimization item is deleted.
