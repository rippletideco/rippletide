# List Optimization Knowledge

View source knowledge elements that can be reviewed or converted into stronger
evaluation questions.

Use this to identify facts that are good candidates for new tests.

## Endpoint

```http
GET /api/agents/{agentId}/optimization-knowledge-elements
```

## Authentication

Send your platform API key in the `x-api-key` header.

## Path Parameters

| Name | Type | Description |
| --- | --- | --- |
| `agentId` | `string<uuid>` | Evaluation agent ID. |

## Success Response

Returns `200 OK` with knowledge elements that can be used for dataset
improvement.
