# Update Optimization Item

Edit or approve a candidate dataset improvement.

Use this after reviewing an optimization item and deciding whether its generated
question and answer are ready for use.

## Endpoint

```http
PATCH /api/agents/{agentId}/optimization-items/{itemId}
```

## Authentication

Send your platform API key in the `x-api-key` header.

## Path Parameters

| Name | Type | Description |
| --- | --- | --- |
| `agentId` | `string<uuid>` | Evaluation agent ID. |
| `itemId` | `string<uuid>` | Optimization item ID. |

## Request Body

```json
{
  "question": "Can customers get a refund after 30 days?",
  "answer": "No. Refunds are available within 30 days unless support approves an exception.",
  "approved": true
}
```

## Success Response

Returns `200 OK` with the updated optimization item.
