# Clear Evaluation Results

Clear stored evaluation results for an agent.

Use this before rerunning a clean evaluation pass while keeping the agent,
knowledge, and evaluation questions intact.

<Warning>
  This clears saved result records. It does not delete the agent or its
  evaluation questions.
</Warning>

## Endpoint

```http
POST /api/agents/{id}/test-results/reset
```

## Authentication

Send your platform API key in the `x-api-key` header.

## Path Parameters

| Name | Type | Description |
| --- | --- | --- |
| `id` | `string<uuid>` | Evaluation agent ID. |

## Success Response

Returns `200 OK` when the stored results have been cleared.
